# Python-Practise

Day-1 :
PALLINDROME NUMBER :- When a number is reversed , if that reversed number is same as the orginal number then that number is called pallindrome

Day-2 :
ARMSTRONG NUMBER :- If the sum of powers of the digits in a number is equal to the original number then that number is called Armstrong number

Day-3 :
NEON NUMBER :- If the sum of digits in a square of a number is equal to the original number then that number is called Neon number 

Day-4 :
CENTER PYRAMID :- To print a Pyramid shape pattern with stars " * "                                                                                 
INVERTED PYRAMID :- To print a Inverted Pyramid shape with stars " * " in reverse order

Day-5 :
DIAMOND PATTERN :- Printing stars "*" to form a Diamond shape

Day-6 :
HALF DIAMOMND :- Printing only a half pattern in a Diamond
